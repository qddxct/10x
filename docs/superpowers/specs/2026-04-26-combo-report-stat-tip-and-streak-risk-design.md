# 二串一报告统计提示与连中连不中风险设计

## 背景

二串一报告中的 `ROI 均值`、`P90`、`模型分位` 对非技术读者不够直观。高赔率组单策略还存在经营层面的风险：即使长期 ROI 较好，如果连续不中的票数过多，客户信心会下降，进而影响投注站销售量。

## 目标

1. 在 `/combo-reports/[runId]` 的“随机对照”区域增加统计口径说明。
2. 在二串一逐票明细的每个分组中展示连中、连不中指标。
3. 指标文案使用中文业务语言，避免只展示技术名词。
4. 保持现有报告结构，不改变模型选号逻辑。

## 指标口径

### ROI 均值

多次随机组单试验后的平均收益率，用来看随机买的整体水平。

### P90

随机结果中前 10% 的门槛。例如 P90 为 60%，表示只有约 10% 的随机结果能超过 60% ROI。

### 模型分位

模型 ROI 在随机结果中的排名位置。例如 99%，表示模型超过了 99% 的随机结果。

### 最大连中

按二串一票序列统计，连续命中的最长票数。

### 最大连不中

按二串一票序列统计，连续未命中的最长票数。这个指标用于衡量经营风险：连不中越长，越容易影响客户信心和销售热度。

## 数据设计

扩展 `GET /api/research/{run_id}/ticket-groups` 的 `summary`：

```json
{
  "ticket_count": 139,
  "stake": 13900,
  "returns": 20811.62,
  "pnl": 6911.62,
  "roi": 0.4972,
  "max_hit_streak": 2,
  "max_miss_streak": 14
}
```

后端根据每组 `tickets` 的 `is_hit` 顺序计算，不依赖历史脚本是否提前保存该字段。

## 前端设计

1. “随机对照”说明区改为小提示卡片，包含：
   - `ROI 均值` 的解释。
   - `P90` 的解释。
   - `模型分位` 的解释。
   - `最大连不中` 的经营含义。
2. 每个二串一分组摘要展示：
   - 票数、投入、回收、盈亏、ROI。
   - 最大连中、最大连不中。
3. 文案中明确“期次按一张二串一票统计”。

## 验收标准

1. 页面能看到 `统计口径说明`。
2. 页面能看到 `ROI 均值`、`P90`、`模型分位`、`最大连不中` 的解释。
3. 每个二串一明细分组能看到 `最大连中` 和 `最大连不中`。
4. 后端 API 测试覆盖 streak 计算。
5. 前端组件测试覆盖提示文案和 streak 展示。
