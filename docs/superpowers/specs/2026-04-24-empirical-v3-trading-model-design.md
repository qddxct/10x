# Empirical V3 平/让平交易模型设计

日期：2026-04-24
状态：Revised，执行中

## 0. 修订记录

2026-04-24 首轮实现和回测后修订：

| 规则 | 首轮下注数 | 命中 | ROI | 决策 |
| --- | ---: | ---: | ---: | --- |
| HDRAW_A | 47 | 17 | +29.91% | 保留为 V3 唯一激活规则 |
| HDRAW_C | 76 | 21 | -4.84% | 暂停 |
| DRAW_A | 120 | 36 | -8.25% | 暂停 |

修订原因：

1. 首轮 `empirical-v3-candidate` 全样本 ROI 只有 +0.20%，低于 v2 的 +18.21%。
2. 收益被 HDRAW_C 和 DRAW_A 稀释；HDRAW_A 单独表现更强。
3. HDRAW_A 单独 90 天窗口为 5/7 正 ROI，并且 5/7 窗口 ROI 不低于 v2。
4. 因此 V3 candidate 不再激活 HDRAW_C/DRAW_A，只保留最强、最可解释的让平规则。

## 1. 背景

现有 `empirical-v2-d104-h104-clean` 在最近样本表现较好，但向更早半年数据回测后明显退化，存在过拟合风险。当前数据库已经有较完整的历史样本：

- 完整样本：3267 场
- 时间范围：2024-09-28 至 2026-04-22
- 完整定义：赛果 + Titan007 欧赔/亚盘 + Titan007 `analysis/*cn.htm` 球队状态
- 结算赔率：优先使用竞彩官方 HAD/HHAD，缺失时回退 Titan007

本设计不把《平让平竞彩交易模型手册》当作正确规则，只把它作为目标描述：我们要做的是平/让平概率交易模型，而不是每天强行推荐。

## 2. 目标

V3 的目标是建立一个更抗过拟合的候选模型，重点满足：

1. 优先提高长期 ROI，而不是单纯提高推荐数量。
2. 允许空仓，减少低质量推荐。
3. 以让平结构为主，普通平只保留极窄高质量条件。
4. 规则必须可解释、可审计、可回测。
5. 不覆盖 `default` 和 `empirical-v2-d104-h104-clean`，只新增候选模型。

非目标：

1. 不做机器学习黑盒模型。
2. 不做 2 串 1 组合优化。
3. 不引入新增外部数据源。
4. 不承诺正收益，不把历史收益视为未来收益保证。

## 3. 实证依据

详见：

- `docs/analysis/2026-04-24-model-edge-diagnosis.md`
- `docs/analysis/2026-04-24-walk-forward-edges.md`

全样本基线：

| 目标 | 下注数 | 命中 | 命中率 | ROI |
| --- | ---: | ---: | ---: | ---: |
| 普通平 | 3261 | 830 | 25.45% | -9.52% |
| 让球平 | 3267 | 791 | 24.21% | -11.87% |

关键发现：

1. 普通平整体不可作为主战场。
2. 手册中的普通平甜区在完整样本上并不稳定盈利。
3. 让平存在更明确的结构优势，尤其是“一球附近 + 强弱差不极端 + 让平赔率达标”。
4. 过高平赔、欧赔离散大、深盘对普通平很不友好。
5. 一些历史平局率信号在去泄漏后方向反转，不能直接沿用旧 v1 结论。

## 4. V3 总体策略

V3 不再做“平和让平平均发力”的综合模型，而是拆成两个决策通道：

1. 主通道：让平结构模型。
2. 副通道：暂不启用，普通平只保留在研究报告中，不进入 candidate 模型。

推荐优先级：

1. 命中 HDRAW_A 时优先推荐 `handicap_draw`。
2. 不命中 HDRAW_A 时不推荐。
3. HDRAW_C 和 DRAW_A 暂停，不进入 `empirical-v3-candidate`。

## 5. 候选规则

### 5.1 HDRAW_A：一球强弱差赔率

用途：主力让平规则。

条件：

- `abs(handicap_value)` 在 `1.00 ~ 1.25`
- `rank_gap` 在 `6 ~ 15`
- 竞彩让平赔率或 Titan007 让平赔率 `>= 3.5`

实证表现：

| 指标 | 值 |
| --- | ---: |
| 样本 | 61 |
| 命中 | 23 |
| 命中率 | 37.70% |
| ROI | +36.87% |
| Walk-forward 正 ROI 窗口 | 6/6 |

解释：

这个结构更接近“强队可赢但不易打穿”的价格表达。盘口在一球附近，排名差存在但不极端，让平赔率又给出足够收益空间。

风险：

样本只有 61 注，数量不大。实现时必须保守，不应为了扩大推荐量放宽过多条件。

### 5.2 HDRAW_C：一球/半一强弱差扩展

用途：让平补充研究规则，当前不激活。

条件：

- `abs(handicap_value)` 在 `0.75 ~ 1.25`
- `rank_gap` 在 `6 ~ 15`
- 竞彩让平赔率或 Titan007 让平赔率 `>= 3.3`

实证表现：

| 指标 | 值 |
| --- | ---: |
| 样本 | 152 |
| 命中 | 47 |
| 命中率 | 30.92% |
| ROI | +9.57% |
| Walk-forward 正 ROI 窗口 | 5/7 |

解释：

这是 HDRAW_A 的宽口径版本，用于补充样本量。但首轮 v3 回测中该规则 ROI 为 -4.84%，因此当前不进入 candidate 模型。

风险：

2025-06~2025-11 两个窗口表现转负，首轮实现后全样本也为负，不能作为激进放量规则。

### 5.3 DRAW_A：普通平强交集

用途：普通平研究规则，当前不激活。

条件：

- 主胜欧赔在 `2.30 ~ 2.80`
- 客胜欧赔在 `2.30 ~ 2.80`
- 平赔在 `3.00 ~ 3.20`
- `abs(handicap_value) <= 0.25`

实证表现：

| 指标 | 值 |
| --- | ---: |
| 样本 | 142 |
| 命中 | 47 |
| 命中率 | 33.10% |
| ROI | +0.81% |
| Walk-forward 正 ROI 窗口 | 3/7 |

解释：

普通平只有在强均衡、低平赔压缩、浅盘口同时成立时才接近可用。首轮 v3 回测中 DRAW_A ROI 为 -8.25%，因此当前不进入 candidate 模型。

风险：

总 ROI 仅微正，窗口稳定性一般。首轮实现后表现为负，当前关闭普通平通道。

## 6. 硬过滤器

V3 在进入候选规则前先应用硬过滤器。

普通平过滤：

1. `draw_odds >= 3.8` 不推荐普通平。
2. `odds_balance >= 4.0` 不推荐普通平。
3. `abs(handicap_value) >= 1.5` 不推荐普通平。
4. `venue_draw_sum >= 0.65` 不推荐普通平。

让平过滤：

1. `abs(handicap_value) >= 1.5` 不推荐让平。
2. `venue_draw_sum < 0.35` 不推荐让平。
3. `season_draw_sum < 0.35` 不推荐让平。

其中：

- `odds_balance = max(win_odds, draw_odds, lose_odds) - min(win_odds, draw_odds, lose_odds)`
- `season_draw_sum = home season draw rate + away season draw rate`
- `venue_draw_sum = home home-draw rate + away away-draw rate`
- `rank_gap = abs(home_rank - away_rank)`，任一排名缺失则为 `None`

## 7. 评分与推荐语义

V3 可以继续复用 `SportteryMatchScore.total_score`，但分数语义从“多维加权总分”变为“规则置信等级”。

建议分数：

| 命中结构 | bet_type | total_score | kelly_pct |
| --- | --- | ---: | ---: |
| HDRAW_A | handicap_draw | 112 | 0.015 |
| HDRAW_C | null | 0 | 0 |
| DRAW_A | null | 0 | 0 |
| 未命中 | null | 0 | 0 |

说明：

1. 分数只用于排序和展示，不代表线性概率。
2. Kelly 比例先保守，不沿用历史高收益窗口放大仓位。
3. 后续若要做真实 Kelly，需要先建立独立概率校准表。

## 8. 回测验证方案

V3 必须通过以下回测，不允许只看全样本：

1. 全历史样本：2024-09-28 至最新已完赛日期。
2. 90 天窗口滚动回测。
3. 按 bet_type 拆分：`draw` 与 `handicap_draw`。
4. 与 `default`、`empirical-v2-d104-h104-clean` 同窗口对比。
5. 输出每个窗口：下注数、命中数、命中率、固定 ROI、Kelly ROI、盈亏。

通过标准：

1. V3 全样本 ROI 高于 `default` 和 v2。
2. V3 至少 70% 的有效 90 天窗口 ROI 不低于 v2。
3. V3 不允许靠单个窗口贡献超过总利润的 50%。
4. `HDRAW_A` 必须单独展示，不被其他规则混淆。
5. 如果普通平通道亏损，必须支持关闭 DRAW_A 后重新回测。

## 9. 数据质量约束

V3 只使用以下数据：

1. Titan007 历史分析页 `analysis/{id}cn.htm` 解析出的球队状态。
2. Titan007 历史赔率接口。
3. 竞彩官方结算赔率。
4. 已完赛赛果。

禁止使用：

1. 当前时刻球队状态替代历史赛前状态。
2. 赛后刷新后的排名或积分数据。
3. 与赛果直接相关的未来信息。
4. 人工复盘结果作为模型输入。

## 10. 实现范围

允许新增：

1. `empirical_v3` 策略函数。
2. 单元测试覆盖 HDRAW_A、HDRAW_C、DRAW_A、硬过滤器。
3. 新模型配置 `empirical-v3-candidate`。
4. 分析/回测脚本或命令，用于生成对比报告。

不允许：

1. 覆盖或删除 `default`。
2. 覆盖或删除 `empirical-v2-d104-h104-clean`。
3. 修改历史比赛、赔率、球队状态数据。
4. 直接激活 v3 作为生产模型，除非回测报告和人工审核通过。

## 12. 风险

1. 样本量仍然有限，尤其 HDRAW_A 只有 61 注。
2. 排名字段缺失较多，导致部分比赛无法进入 rank_gap 规则。
3. 竞彩让平赔率缺失时回退 Titan007 赔率，结算一致性需要继续关注。
4. 规则来自历史扫描，仍有过拟合风险。
5. v3 推荐量可能明显减少，运营上需要接受空仓。
